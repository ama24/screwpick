      Sorting

      Wild bins have no rules: the first part of a new kind takes a free one, and it collects that kind until it is emptied. Bins with rules come first: DIN912_M4x16, DIN912_M4, DIN912, or wildcards like DIN912_M*.

      Grid

      Origin: printer X/Y of the grid's front-left corner.

      Camera to printer

      1. Put at least 3 bins far apart on the bed, then Take photo.
      2. Jog the picker tip onto the centre of a marker, then Tip is here on its row.
      3. Repeat for 3 or more markers, then Fit. Errors under 0.5 mm are good.
      4. Check moves the tip 2 mm above a marker with the fitted calibration.

      Bin sizes

      Each size has its own range of codes, so the camera knows a bin's size from its code. Every plate is a full build plate of one size for a 220 × 220 bed: all the same height, so one colour change at the rim (21 mm for 3u, 42 mm for 6u) makes all the codes black. The same files are in the repository under prints/.
